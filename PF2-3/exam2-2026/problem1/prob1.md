
$\huge{\color{cadetblue}{\text{Problem 1}}}$

<br/>

For each of the following annotations determine which choice fits on the empty line (.....). The variables x and y are of type int. Note that A and B (capital letters!) are specification constants (so not program variables).

---------------

$\Large{\color{darkkhaki}{\text{Prob 1.1}}}$

```java
// x = A ∧ y = B
.....
// x = 2 * A + B ∧ y = A - B
```

${\color{peru}(a)} \quad x := 2 * x + y; \space y := x - 3 * y;$  
${\color{peru}(b)} \quad y := x - y; \space x := x + 2 * y;$  
${\color{peru}(c)} \quad x, y := 2 * x + y, x - y;$  

<br/>

---------------

$\Large{\color{darkkhaki}{\text{Prob 1.2}}}$

```java
// x = A ∧ y = B
.....
// x = B ∧ y = A
```

${\color{peru}(a)} \quad x := x - y; \space y := x + y;$  
$\qquad \quad x := y - x;$  
${\color{peru}(b)} \quad y := x - y; \space x := x + y;$  
$\qquad \quad y := x - y;$  
${\color{peru}(c)} \quad x := x + y; \space y := x - y;$  
$\qquad \quad x := y - x;$  

<br/>

---------------

$\Large{\color{darkkhaki}{\text{Prob 1.3}}}$

```java
// 3 * x - 2 * y = A
.....
// 3 * x - 2 * y = A
```

${\color{peru}(a)} \quad x := x + 2 * y; \space y := 3 * y;$  
${\color{peru}(b)} \quad x := x + 2 * y; \space y := 4 * x;$  
${\color{peru}(c)} \quad x := x + 2 * y; \space y := 4 * y;$  

<br/>

---------------

$\Large{\color{darkkhaki}{\text{Prob 1.4}}}$

```java
// .....
x := 2 * x - y;
y := x + y;
// x > y
```

${\color{peru}(a)} \quad y < 0$  
${\color{peru}(b)} \quad y > 0$  
${\color{peru}(c)} \quad x > y$  

<br/>

---------------

$\Large{\color{darkkhaki}{\text{Prob 1.5}}}$

```java
// .....
y := x - 2 * y;
x := x + y;
// x < 2 * y
```

${\color{peru}(a)} \quad x < 3 * y$  
${\color{peru}(b)} \quad y < 0$  
${\color{peru}(c)} \quad x < 0$  

<br/>

---------------

$\Large{\color{darkkhaki}{\text{Prob 1.6}}}$

```java
// .....
x, y := x + 2 * y, 3 * x - y;
// x < y
```

${\color{peru}(a)} \quad 4 * x < y$  
${\color{peru}(b)} \quad 2 * x > 3 * y$  
${\color{peru}(c)} \quad 2 * x + 3 * y > 0$
